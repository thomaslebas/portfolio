# Lookback

Subline: Cleaning and exploring old chat logs

I've been chatting on the internet since the early 2000s. What's crazier is that I still hold onto a lot of those chat logs. However, I never really knew what I would do with it, but I've always thought there is some worth.

Again, AI changes the game. An idea emerged. What if I could train an AI model to speak like me, both in tone and with my memories? What if I could talk to my younger self and learn about what I was like?

The first problem is the data: old XML exports are not easy to work with. That led to building a desktop app, a first for me, that parses, cleans, and stores the exports in a structured format that I can take to the next step on this journey.

New to the vibe coding tools, I used this as an opportunity to learn how to iterate on a design as I was building it. No Figma involved.
