# Lookback

Subline: Cleaning and exploring old chat logs
Meta: Desktop app · Vibe coding · Digital archaeology

I've been chatting on the internet since the early 2000s. What's crazier is that I still hold onto a lot of those chat logs. I never really knew what I would do with them, but I've always thought there is some worth. Now it’s 2025, AI is taking hold, and an idea has emerged. What if I could make an AI model speak like me, both in tone and with my memories? What if I could talk to my younger self and learn what I was like? Maybe this is what I can pull from my habit of saving everything?

This is the start of a journey towards that idea. The first problem I need to solve is the data: old XML exports are not easy to work with. This has led to building a desktop app, a first for me, that parses, cleans, and stores the exports in a structured format that I can take to the next step.

At this point I was also new to vibe coding tools. I used this as an opportunity to learn how to iterate on a design as I was building it—no Figma involved.
